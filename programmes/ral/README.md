# Reliable Autonomous Learning (RAL)

*Note: The foundational constitution for this programme is based on an external document (RAL_Constitution.pdf) which is currently pending review. This summary is provisional.*

The Reliable Autonomous Learning (RAL) programme aims to establish trustworthy evidence that an autonomous system genuinely improves from experience, generalizes to unseen tasks, preserves previous capabilities, and avoids evaluator gaming.

## Core Directives

1.  **Genuine Improvement over Behavioral Change**: We must distinguish between a system that learns to be more capable broadly, and one that merely memorizes training examples or games specific evaluation metrics.
2.  **Generalization and Retention**: Adaptation must improve performance on held-out tasks without unacceptable regression on previously mastered capabilities.
3.  **Evaluator Reliability**: As systems learn, they must not learn to exploit weaknesses in automated evaluators.
