# Publication Workflow

Publications in this repository are categorized as Blogs, Articles, or Papers.

## Statuses
- **Blogs and Articles**: `draft`, `review`, `published` (publicly released), `archived`.
- **Papers**: `draft`, `technical-report`, `preprint` (released on arXiv/etc), `submitted`, `accepted`, `published` (peer-reviewed), `withdrawn`.

## Workflow
1. Create a draft using the appropriate template in the `writing/` directory.
2. Fill out the frontmatter metadata.
3. Update the status as the document progresses.
4. "Published" blogs and articles are considered publicly released.
5. Topics tags can be added or changed without moving the file.
