# Contributing to Independent Research

This repository primarily serves as a personal workspace for independent research. While I am not currently seeking direct code contributions or pull requests to the core research projects, I welcome feedback, discussion, and reproduction attempts.

## How to engage

1. **Discussions**: If you have questions about the methodology, find an interesting failure mode, or want to discuss a specific paper, please open an Issue.
2. **Reproducibility**: If you attempt to reproduce an experiment and encounter difficulties, please open a Bug Issue.
3. **Typos and Clarifications**: Minor pull requests fixing typos or clarifying documentation are welcome.

Before contributing, please read the [Code of Conduct](CODE_OF_CONDUCT.md) (to be added) and ensure any discussions remain respectful and constructive.
